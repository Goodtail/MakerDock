# MakerDock 0.1.0

MakerDock starts its public versioning at **0.1.0**. The earlier 1.6.x labels were assigned prematurely. This version includes the current library, print history, and MakerWorld browsing features.

- Organize 3MF files with plate previews, saved time estimates, categories, tags, and favorites.
- Reopen stored models in the separately installed official Bambu Studio.
- Record completed prints with time, filament, and notes; organize multiple models together.
- Browse MakerWorld in the app, open original model/profile links, and jump to all saved models from My Collections.
- Use English, Korean, Japanese, or Simplified Chinese, with system, light, and dark appearance.

Download `MakerDock-0.1.0-universal.dmg` for **macOS 13 or later**, on **Apple Silicon or Intel**. Replace the existing app in Applications to update. Existing model files, notes, and print records stay in place.

Automatic download capture remains disabled in the public app. The Chrome companion extension is planned. See [integration status](../integration-status.md) and [Privacy](../../PRIVACY.md).

Routine development changes will use internal build numbers. Public versions will advance with releases.
