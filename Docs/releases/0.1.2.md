# MakerDock 0.1.2

This release brings the browser and print queue improvements developed after the public 0.1.1 release into one universal Mac download.

## Browse and keep your models

- MakerWorld and My Collections keep their pages when you switch back from the library. Select the active destination again to return to its starting page.
- Open links in tabs with Command-click or the right-click menu. Tabs shrink to share the available width, with overflow controls for larger collections and familiar browser keyboard shortcuts.
- Downloads started inside MakerDock retain their observed original model page more reliably, including redirects and Studio handoffs. Source buttons are easier to find.
- Reuse an archived download, request a fresh one, or open a new Studio working copy while preserving the saved original.
- Open in Fusion exports an STL mesh through a compatible, separately installed official Bambu Studio and opens the installed Autodesk Fusion app. CAD design history is not reconstructed.

## Plan and record prints

- Models without a saved estimate can be calculated when added to the queue, using your configured compatible Studio. The result is saved across the model library.
- Mark a queued model as printing. Started prints use editable start and finish times for completion duration, including pauses, rather than silently replacing elapsed time with an estimate.
- Optionally connect a compatible printer on your local network with its IP, serial, and LAN access code. Explicitly link a live job to a queue item to use reported status and remaining time. Finish records still require your confirmation; no print commands are sent.
- Read [printer setup and limitations](../printer-connection.md) before using the optional connection. Hardware/firmware compatibility varies; actual filament grams are not measured.
- Sidebar, inspector, and queue spacing adapt better to window sizes. Library sorting opens directly and includes short/long print times.

English, Korean, Japanese, and Simplified Chinese are included. The public build keeps experimental network/profile capture and external remote download handoffs disabled. The Chrome companion remains planned.

## Download and update

Requires macOS 13 or later. Universal binary for Apple silicon and Intel. Developer ID: MakerDock maintainer (YOUR_PERSONAL_TEAM_ID). Build 21.

Save your browsing/work before replacing an installed app. Close MakerDock yourself when you are ready, then drag the new copy from the DMG to Applications. The library is stored separately from the app bundle. Browser pages do not have full cross-relaunch session restoration.
