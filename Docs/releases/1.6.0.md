# MakerDock 1.6.0

The first public release of MakerDock, a macOS library for 3MF files and print history.

- Browse models and all available plate previews, with saved print-time estimates.
- Reopen archived models in official Bambu Studio using a working copy.
- Record completed prints with editable time, filament, notes, and file organization.
- Organize multiple models with categories, favorites, and recoverable Trash.
- Choose system, light, or neutral black-and-gray dark appearance.
- Use English, Korean, Japanese, or Simplified Chinese. Each guide includes actual app screenshots.

## Download

Requires **macOS 13 or later**, on **Apple Silicon or Intel**. Download `MakerDock-1.6.0-universal.dmg`, open it, and drag MakerDock into Applications.

The app and DMG are signed with **Developer ID Application: CHANWOO KOO (D523TSBMWR)**, accepted by Apple's notarization service, and stapled. The app inside the final DMG passes Gatekeeper assessment. `SHA256SUMS.txt` contains the checksum of the final installer.

## Integration status

This release manages local files. Embedded MakerWorld browsing and download capture remain disabled pending clarification of permitted use. Source links open in your browser, and previously saved MakerWorld metadata remains available. The **Chrome companion extension is coming soon**.

Print completion is recorded manually. Official Bambu Studio is installed separately and is needed for slicing and compatible local time calculations.
