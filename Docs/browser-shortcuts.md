# Browser tabs and shortcuts

MakerWorld and My Collections each keep their own open tabs while MakerDock is running. Tabs share the available width as more are opened. Once they reach the minimum readable width, use the mouse wheel, trackpad, or arrows to reach the rest. The menu at the right lists every tab by its full title. Selecting a tab brings it into view.

Right-click a MakerWorld link and choose **Open Link in New Tab** to keep reading the current page. WebKit's existing copy, image, and editing menu items remain available. Command-click also opens a background tab; Shift-Command-click switches to the new tab.

These shortcuts apply while a MakerDock browser section is visible, in its own window. Standard macOS window and editing commands remain available elsewhere.

| Action | Mac shortcut |
| --- | --- |
| New tab | Command-T |
| Close tab | Command-W |
| Reopen last closed tab | Shift-Command-T |
| Next / previous tab | Control-Tab / Shift-Control-Tab |
| Next / previous tab | Option-Command-Right / Option-Command-Left |
| Next / previous tab | Shift-Command-] / Shift-Command-[ |
| Select tab 1–8 | Command-1 through Command-8 |
| Select last tab | Command-9 |
| Select address bar | Command-L |
| Back / forward | Command-[ / Command-] |
| Reload / reload from origin | Command-R / Shift-Command-R |
| Find in page | Command-F |
| Next / previous match | Command-G / Shift-Command-G |
| Zoom in / out / reset | Command-+ / Command-- / Command-0 |
| Close find; otherwise stop loading | Escape |

A tab importing a file stays open until its import finishes. Reopening a closed tab restores its URL, not unsaved form contents or page history. Page zoom belongs to each tab and ranges from 50% to 300%.

The familiar bindings follow [Chrome's Mac shortcut reference](https://support.google.com/chrome/answer/157179?hl=en). MakerDock does not implement Chrome features such as extensions, bookmarks, or private browsing.
