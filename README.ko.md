## 만든 이유

마음에 드는 모델을 찾아 3MF를 받고 Studio로 엽니다. 며칠 뒤 다시 출력하려는데 어디 저장했는지 기억이 안 나 또 다운로드합니다. 다운로드 폴더에는 파일이 쌓이지만, Finder에서는 어떤 플레이트가 들어 있는지, 출력에 얼마나 걸리는지, 이미 출력한 모델인지 알기 어렵습니다.

**MakerDock은 받은 모델을 모으고, 실제로 출력한 기록을 함께 보관합니다.** 파일명 대신 미리보기로 찾고, 이미 받은 파일을 다시 열고, 결과는 그 모델 옆에 남겨두세요. 공식 Bambu Studio와 함께 사용하는 보조 앱이라 별도 개조 슬라이서를 설치할 필요도 없습니다.

## 파일이 쌓인 폴더를, 찾기 쉬운 보관함으로

| 이런 불편이 있었다면 | MakerDock에서는 |
| --- | --- |
| “그 모델 어디 저장했더라?” | 격자·목록 보기, 검색, 분류, 태그, 즐겨찾기로 찾습니다. |
| “이거 전에 받은 파일 아닌가?” | 내용이 완전히 같은 파일은 해시로 확인해 하나로 모으고, 원래 있던 위치를 기억합니다. 다른 프로필은 별도로 남습니다. |
| “플레이트마다 뭐가 들어 있지?” | 저장된 플레이트 미리보기를 한꺼번에 보고, 누르면 크게 확인합니다. |
| “출력에 얼마나 걸리지?” | 3MF에 저장된 시간을 표시합니다. 기존 MakerWorld 예상 정보가 있으면 우선 표시하고, 설치된 Studio로 내 프린터 기준 계산도 요청할 수 있습니다. |
| “이거 이미 출력했나?” | 완료·미완료 보기를 나누고 출력별 시간, 필라멘트, 메모를 기록합니다. |
| “파일 수십 개를 어떻게 정리하지?” | 여러 모델을 선택해 분류, 즐겨찾기, 완료 처리, 휴지통 이동과 복원을 한꺼번에 합니다. |

### 플레이트를 한눈에

드롭다운을 하나씩 바꾸지 않아도 됩니다. 모든 플레이트 미리보기가 목록에 보이고, 누르면 크게 열려 Studio로 보내기 전에 내용을 확인할 수 있습니다.

![플레이트 확대 보기](Docs/screenshots/ko/plates.png)

### 출력 기록도 번거롭지 않게

완료로 표시하고, 미리 채워진 시간을 확인한 뒤 저장하세요. 예상 시간은 수정할 수 있고, 정보가 있으면 필라멘트 종류·색상·사용량도 함께 기록합니다. 다음 출력에 참고할 메모도 남겨두세요. 완료한 보관 파일은 전용 폴더로 옮겨지며, 저장 전 대화상자에서 해당 이동 내용을 확인할 수 있습니다.

![시간과 필라멘트, 메모를 함께 남기는 출력 완료 화면](Docs/screenshots/ko/print-record.png)

### 여러 모델을 한 번에 정리

선택 모드에서 카드를 여러 개 고르세요. 같은 분류로 묶거나, 출력 완료로 표시하거나, 복원 가능한 휴지통으로 보낼 수 있습니다. 일괄 완료 시에도 각 모델의 시간과 필라멘트 기본값은 따로 유지되고, 공통 메모를 더할 수 있습니다.

## 함께 들어 있는 기능

- **폴더 자동 확인과 드래그 앤 드롭:** 3MF를 직접 가져오거나 선택한 폴더를 확인합니다.
- **보관 원본 보호:** Studio에서는 별도 작업 사본을 열어, 편집으로 보관 원본이 덮어써지지 않습니다.
- **파일 옆에 원본 링크:** MakerWorld 모델·출력 프로필 주소를 연결하고 브라우저로 엽니다. 이전에 저장한 웹 정보도 보관함에 유지됩니다.
- **내 프린터 설정:** 프린터·노즐·출력 품질을 선택하거나 공식 Studio의 선택값을 가져옵니다. 호환되는 로컬 계산 결과는 재사용합니다.
- **되돌릴 수 있는 정리:** 휴지통에서도 분류·메모·출력 기록을 함께 복원합니다. 보관함 항목 삭제로 외부 원본을 지우지 않습니다.
- **네 언어 지원:** 설정에서 한국어, 영어, 일본어, 중국어 간체를 선택합니다.
- **내 Mac에 저장:** 보관함에 MakerDock 계정이나 분석 수집, 클라우드 업로드가 필요하지 않습니다.

## 시작하기

1. [Releases](https://github.com/Goodtail/MakerDock/releases)에서 DMG를 받으세요. 서명·공증 상태는 해당 릴리스 설명에 표시합니다.
2. **MakerDock**을 **Applications** 폴더로 옮깁니다. macOS 13 이상, Apple Silicon과 Intel을 지원합니다.
3. `.3mf` 파일을 가져오거나 창에 끌어 놓고, 필요하면 자동 확인할 폴더를 고릅니다.
4. 모델을 확인해 별도로 설치한 **공식 Bambu Studio**에서 열고, 실제 출력이 끝나면 완료 기록을 남깁니다.

보관함 보기와 수동 기록에는 Studio가 필요하지 않습니다. 슬라이싱과 Studio 기반 시간 계산에는 필요합니다.

## 예상 시간과 실제 출력 기록

아직 슬라이싱하지 않은 3MF에는 모양과 설정만 있고 시간이 없을 수 있습니다. 프린터 기종만 고르면 정확한 시간이 생기는 것은 아니며 슬라이싱이 필요합니다. MakerDock은 호환되는 공식 Studio에 파일 사본과 임시 설정으로 계산을 요청할 수 있습니다. 출력 전 최종 설정은 Studio에서 확인하세요.

출력 완료는 **사용자가 직접 기록**합니다. 프린터의 작업 완료를 자동 감지하거나, 실시간 AMS 재고를 읽거나, 실제 소모량을 측정하지는 않습니다. 실제 결과가 다르면 미리 채워진 시간과 필라멘트 값을 수정하세요.

## 출시 예정

- **Chrome 보조 확장 프로그램 — 출시 예정:** 모델·프로필 정보를 보관함에 연결하고, 이미 받은 파일을 다시 활용하는 흐름을 준비하고 있습니다.
- **앱 안의 MakerWorld 자동 보관 — 실험 단계:** 개발 소스에는 웹 탐색·다운로드 감지·프로필 재사용 기능이 있으나, 서비스 이용 허용 범위를 확인하기 전까지 공개 DMG에는 활성화하지 않습니다.

현재 공개 버전은 로컬 파일 관리 중심입니다. MakerWorld 다운로드를 가로채거나 Bambu Studio의 URL 처리 앱으로 등록하지 않습니다. 오픈소스 라이선스가 외부 서비스나 모델의 이용 권한까지 주는 것은 아닙니다. [연동 현황](Docs/integration-status.md)을 참고하세요.

## 개발과 라이선스

SwiftUI·AppKit과 Swift 3MF 라이브러리로 만들었으며, ZIP 처리는 ZIPFoundation을 사용합니다. 운영·개발 앱은 식별자와 보관함이 분리되어 있고, 개발 앱에는 DEV 아이콘 배지가 표시됩니다.
